LEX Pipeline Theater

How four ways of feeding a language model the right text differ, on three real questions. Each model searches a library, builds an evidence box (the only text the answering model may read), and a judge scores the answer. Pick an example, a model and a box size, press play, and click anything in the 3D scene to see what it is and what it did. Every number is from recorded runs of the 24-question screen (2026-09-26).
